Inter 4.1 (rsms/inter, SIL OFL 1.1, see OFL.txt).

- `Inter-Regular.ttf`: UI text.
- `InterNum-Regular.ttf`: Inter with tabular figures frozen on (`pyftfeatfreeze -f tnum -S -U Num`):
  prices and sizes line up in columns without a monospaced face. egui has no OpenType feature support.
- `InterDisplayNum-Medium.ttf`: Inter Display Medium, tabular figures frozen on; headline numbers and headings.

CJK and Hangul come from the system (PingFang / Microsoft YaHei / Yu Gothic / Malgun / Noto CJK).
