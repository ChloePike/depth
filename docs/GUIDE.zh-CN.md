# Depth 使用指南

[English](GUIDE.md)

## 1. 安装

| 系统 | 文件 | 说明 |
|---|---|---|
| macOS（Apple 芯片） | `Depth-macos-arm64.zip` | 未公证：第一次打开请**右键 Depth.app → 打开 → 打开**（或执行一次 `xattr -dr com.apple.quarantine /Applications/Depth.app`）。 |
| Windows x64 | `Depth-windows-x64.zip` | 未签名，SmartScreen 会提示一次。 |
| Linux x64 | `Depth-linux-x64.tar.gz` | 需要支持 OpenGL / Vulkan 的桌面环境。 |

下载：[最新版本](https://github.com/ChloePike/depth/releases/latest)。
Depth 从你的电脑直接连交易所。你的网络或地区连不上的交易所会在状态栏里显示红色，其他交易所照常工作。

## 2. 窗口

```
┌ 标题栏：交易对 · 综合价格 · 现货 | 杠杆 | 永续 | 期权 · 时钟 · 下单面板 · 设置 ┐
│ 行情条：标记价、指数价、资金费率 + 倒计时、24h 涨跌/区间/成交量、持仓量、基差、CVD │
├──────────────────────────────┬──────────────┬─────────────────────────┤
│ 图表工具栏：周期 · 数据源 ·  │ 订单簿 · 成交 │ 下单面板（永续）          │
│ 指标 · 布局 · 提醒 · 回放 ·  │ · 交易所 ·   │ 账户卡片                  │
│ 画图工具                     │ 量化         │ 仓位保险                  │
│ 图表（1–4 个格子）           │              │                           │
├──────────────────────────────┴──────────────┴─────────────────────────┤
│ 持仓 · 当前委托 · 止盈止损 · 信号 · 委托/成交/仓位历史 · 下单日志 · 资产 │
├────────────────────────────────────────────────────────────────────────┤
│ 状态栏：各交易所及延迟（点击断开/重连）· 消息数/秒 · 内存 · 时钟 · 语言    │
└────────────────────────────────────────────────────────────────────────┘
```

- **窗口**：拖标题栏移动，拖任意边缘调整大小。窗口位置和大小都会记住，图表、订单簿的选择、布局和所有设置也会记住。
- **交易对**：点交易对（⌘K），输入搜索，回车打开。★（⌘D）加入自选，⌘[ / ⌘] 在自选之间切换。列表覆盖 Binance、Bybit、OKX、Bitget、Gate、MEXC、Hyperliquid 上的所有永续（状态栏里关掉的交易所不计入），并缓存在本地，启动时立刻可用。分类：加密货币、股票、ETF 与指数、大宗商品、外汇、上市前。股票显示交易所代码和公司名（可切换"代码 / 名称"）；按代码、公司名或任一交易所的叫法都能搜到（BB 找到 BlackBerry，GOLD 找到 XAU）。列：最新价、24 小时涨跌、成交额、持仓量（只汇总开着的交易所）、每小时资金费率及年化。
- **股票和大宗商品**：按 Binance 的名字选（XAU、BZ、CL、AAPL……）。Depth 会在其他交易所找到同一个市场，不管它们叫什么（Hyperliquid 的 `xyz:GOLD`、Lighter 的 `BRENTOIL`、MEXC 的 `UKOIL`、`AAPLSTOCK`……），然后一起聚合。如果某个交易所同名的市场其实是另一个东西（计价货币不同、价格单位不同），会被排除在外。
- **市场**：现货 / 杠杆 / 永续 / 期权（⌘1–⌘4）。
- **交易所开关**：在状态栏点击某个交易所就断开它，只关闭这一家的连接。延迟颜色：绿色 < 150 ms，橙色 < 400 ms，更高为红色。
- **下单面板**：⌥⌘I。**设置**：⌘,。

## 3. 图表

**基本操作**
- 周期按钮或 ⌃1–⌃6（1m、5m、15m、1H、4H、1D）；下拉箭头里还有其他周期，最长到 1W。
- *Aggregate* 表示聚合所有交易所（K 线跟随综合指数，成交量和 CVD 来自所有交易所的成交）；也可以只选一家，看它的原始价格。
- 滚轮或双指缩放时间轴，拖动平移，拖价格轴缩放价格，双击复位。价格轴下方角落的 `%` 和 `log` 切换刻度。*Latest* 回到最新。
- **布局**（矩形按钮）：1 个、左右 2 个、上下 2 个、3 个或 4 个图表。点击某个格子把它设为当前图表，工具栏控制的就是高亮的那个。画线按交易对共享。

**指标**（*Indicators* 菜单；均线长度、布林带、RSI / MACD 等参数直接在菜单里改；图例第三行列出每个叠加指标的名字和当前值）

| 指标 | 显示什么 |
|---|---|
| 均线 | 最多三条，长度可调。 |
| 布林带 | 均值 ± k 倍标准差。 |
| 当日 VWAP ±1σ ±2σ | 从 UTC 0 点起的成交量加权均价，带通道。 |
| 成交量分布 | 可见范围内各价位的成交量（左侧）：**POC** 成交最多的价位，**VAH / VAL** 70% 价值区的上下沿，**S / R** 价格下方 / 上方的高成交量节点。 |
| 突破 | 最近一根收盘穿过 VAH、VAL 或节点的 K 线：*Broke up / Broke down*；价格又收回原来那一侧后显示 *Failed break*。 |
| 预期波动锥 | 根据波动率模型给出未来 30 根 K 线的 ±1σ / ±2σ 区间。 |
| 标记价 | 紫色线和价格轴标签（聚合视图按各交易所持仓量加权）。 |
| 订单簿热力图 | 挂单随时间的分布，从启动开始实时记录（1m 周期效果最好）。 |
| 流动性墙 | 挂单量远超订单簿平常水平、并且在最近一分钟大部分时间都在的价位。 |
| 清算热力图 | 估算的清算价位：一张"时间 × 价格"的热力图（每个价位从形成那一刻画到被价格扫掉为止），右侧另有一个剖面；价格上方是空头、下方是多头。用所有交易所的成交量和典型杠杆分布估算，并用真实清算历史校准过。鼠标停在剖面上可以看到金额。 |
| 足迹图 | 每根 K 线内各价位的主动买卖量（*cluster bars* 或 *side clusters*）。 |
| 大单气泡 | 大额成交画在 K 线上，按金额大小显示（门槛在菜单里设）。 |
| 副图 | 成交量、Delta、CVD、持仓量、资金费率、基差、溢价、订单流失衡、订单簿流量、多空比、RSI、MACD。 |

**价格轴标签**：最新价（带 K 线倒计时）和买一 / 卖一优先，其次是标记价和你自己的持仓、挂单线。POC、价值区、支撑阻力、VWAP、突破这些参考线，只有在标签能放在自己价格旁边时才显示标签；放不下就只保留线和图例里的数值。

**画图工具**（工具栏右侧）：矩形、斐波那契、射线、趋势线、水平线；⋯ 里还有通道、文字、测量、多空仓位工具。Esc 取消当前工具。
右键画好的图形可以改颜色、实线 / 虚线 / 点线，设价格提醒、锁定、删除。⌘Z / ⇧⌘Z 撤销 / 重做；眼睛按钮隐藏所有画线，垃圾桶清空当前交易对的画线。

**价格提醒**：右键图表（或水平线 / 射线）→ *Price alert*。*Alerts* 菜单列出所有交易对上已设置的提醒和对应的提示音（内置或系统声音）。价格穿过时播放声音并弹出通知；其他交易对的提醒在后台监控。

**K 线回放**：点 *Replay*，选择起点那根 K 线，然后播放 / 暂停、按 → 单步、调整速度。再点一次 *Replay* 退出。

**在图表上交易**（需要有交易权限的 key）：持仓、挂单、止盈止损触发价和强平价都会画成带标签的线。拖动挂单线就是改单（Bybit 和 Binance 直接改单；其他交易所是先撤再下，确认框里会写明），拖动止盈止损线就是改触发价。价格轴上的 **+** 把该价格填进下单面板。

## 4. 订单簿一栏

- **Book**：所有交易所聚合（每家按自己的中间价对齐，仅供查看），或单个交易所的原始订单簿（点击价位把价格填进下单面板）。菜单：数据源、价格精度（从交易所最细的一档开始，每档 10 倍，BTC 是 0.1 / 1 / 10 / 100）、数量单位（币或 USDT）。鼠标停在聚合的价位上，可以看到这一档在各交易所的分布。
- **逐笔订单（L3）**：价位底部的细条显示挂在这一档的每一张单子（如果能拿到）：Lighter 是精确数据，OKX 和 Hyperliquid 根据订单数推断（会标明）。小单合并显示；鼠标停在色块上能看到大小和挂了多久。Hyperliquid 可以改用 Flowscan 的更快数据（设置 → 通用 → 数据源；第三方服务，默认关闭）。
- **成交**（订单簿下方，可在 设置 → 通用 → 订单簿 里关掉）：实时成交流，标出每笔成交的交易所；*MIN* 按金额过滤。被吃掉的价位会短暂闪一下。
- **Venues**：各交易所在成交量和 ±1% 挂单深度里的占比。
- **Quant**：波动率预测和状态、买卖压力、持仓成本（年化资金费率和基差）。

## 5. 信号

*Signals* 标签页：成交量异动、连环清算、持仓量与价格背离、资金费率拥挤、现货与永续资金流向、基差极值、大单成交、偏离指数的交易所。阈值按每个币自己的历史自动调整；同一类信号 10 分钟内最多出现一次，除非变得更强。信号只描述正在发生什么，不是交易建议。

**猎庄页面**（*期权* 右边的 *猎庄*）：Binance、Bybit、OKX、Bitget、Gate、MEXC、Hyperliquid 的全部永续和现货放在一张表里，每个币一行。
- 列：庄感分、15m 和 1h 涨跌、放量倍数（最近 15 分钟对比全天平均）、最极端的每小时资金费率及其交易所、1h 持仓量变化、最大跨所价差（S 现货、P 永续，标出两边交易所）、24h 成交额。鼠标停在行上可看 5m 涨跌、15m 持仓量变化、爆仓、哪家先动和交易所列表。15m / 1h 要页面运行够这么久才有数。
- **庄感分**（0-100）：用最近 30 天的小时线，对照已记录的坐庄币的六个特征打分（频繁出现 20 倍放量、上下双向插针、单日 20% 的天数、上线时间短、合约成交额超过现货 30 倍或没有现货、7 天内翻倍）。需要 7 天的小时数据（不满时显示 *收集中 n/7*；启动时从 Binance / Bybit 补拉，之后自己记录）。它只说明这是什么类型的币，不预测什么时候拉；权重还没校准。
- 筛选：最低 24h 成交额、交易所、*主流币*（默认隐藏）、币名、*庄感 ≥*。代币化的股票、商品和外汇永远排除。点一行在永续里打开该币，5 分钟 K 线并打开持仓量和资金费率副图。
- 提醒（右栏）：5m 涨跌、放量倍数、负资金费率、跨所价差（两边日成交额都超过 100 万美元，且连续两次检测都在）。提醒写进提醒日志，点一行打开该币。系统通知默认关闭，在 *设置 → 通用 → Hunter 系统通知* 打开。

## 6. 连接交易所账户

设置 → **API Keys**。Key 保存在系统钥匙串里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），从不写进文件。

1. 在交易所创建 key。**先用只读权限**；要下单时才加交易权限。**永远不要开提现权限。** 交易所支持的话，绑定你的 IP。
2. 填入 Depth 要求的字段：

   | 交易所 | 字段 |
   |---|---|
   | Binance、Bybit、Gate、Kraken | API key、secret |
   | OKX、Bitget | API key、secret、passphrase |
   | Hyperliquid | 账户地址（0x…）、API 钱包私钥（API 钱包无法提现） |
   | Lighter | `账户编号:API key 编号`、API key 私钥 |

3. *Save*，然后 *Test*。

只读 key 会被自动识别（Binance、Bybit、OKX）：能看账户，但下单按钮和图表交易会被禁用。Binance 统一账户（Portfolio Margin）和 Bybit 统一账户自动识别。
Bybit 和 Binance 已在真实账户上验证；其他交易所标记为 *untested*，请先用最小数量试。

## 7. 交易

**下单面板**（永续）
1. 顶部：交易所（或 *Smart* 智能路由）、持仓模式、杠杆。下面是该交易所自己的买一 / 卖一和价差。
2. *Open* 开仓 / *Close* 平仓；*Limit* 限价、*Market* 市价、*Stop* 止损单，或 *More*（追踪止损、阶梯单、TWAP）。
3. 价格：手动输入、在单个交易所的订单簿上点击，或用 **BBO**：订单到达交易所时按对手方（*Counterparty*）或己方（*Queue*）第 1 / 5 / … 档定价。
4. 数量按币填，或拖滑块（100% = 可用保证金 × 杠杆）。
5. 可选止盈止损，成交后作用于整个仓位。每个输入框旁的 **⇄** 在价格和 **PnL %**（ROE：盈亏 ÷ 初始保证金，按这笔单的价格和杠杆）之间切换；换算出的价格显示在输入框下方，发出去的就是这个价格。
6. 按钮下面按方向显示：**预估强平价**、**保证金**、**最大可开**，然后是 maker / taker 费率、订单价值和手续费。
   - 逐仓 / 普通账户：按当前杠杆、0.5% 维持保证金率估算。
   - Binance 统一账户 / Bybit 统一账户：这笔单成交后、其他持仓不变时，**整个账户**被强平的价格（uniMMR 1.05 / 维持保证金率 100%）。
   两种都带"≈"，交易所自己的数字可能略有不同。
7. *Open Long* / *Open Short* → 确认框（路由、每一腿、数量、价格、手续费、滑点）→ 回车。

下单永远用所选交易所自己的订单簿、自己的计价货币定价，从不使用综合指数。交易所用别的名字上市的市场（见第 2 节）暂时不能在 Depth 里下单：订单会被拒绝，而不是下到错误的品种上。

**当前委托**：点订单的价格、数量（整笔订单，含已成交部分）或金额，输入后回车。Bybit 和 Binance 永续原地修改（订单号不变）；其他交易所先撤单，撤成功后按新的条件下剩余部分。修改前先按交易所的价格步长、数量步长、最小值和你的风控限额检查，并在确认框里显示。

**风控限额和紧急停止**（设置 → 交易 → *风控限额*）：单笔最大订单价值、标记价附近的价格带、每个币的持仓限额、每日亏损止损（触发后本地午夜前只能平仓）。Depth 发出的每笔永续订单发送前都会检查；平仓从不被拦截。账户栏里红色的 *一键清仓* 按钮（或它的快捷键）在确认一次后，撤销所有已配置 API key 的交易所上的全部订单、止盈止损和算法单，并平掉所有仓位。

**智能路由**（设置 → 交易）：按各交易所自己的订单簿和手续费，在你设定的滑点和拆单限制内把大单拆到多个交易所；*Fixed* 全部发到一个交易所。

**持仓标签页**
- 数量、开仓价、标记价、强平价、保证金（全仓 / 逐仓）、盈亏和收益率。
- **Est. Funding**：当前费率和倒计时、下一次预估支付。
- **Funding paid**：开仓以来收到（+）或支付（−）的资金费，以及从什么时候算起。
  - Binance 和 Bybit：把交易所资金费流水加总到开仓那一笔成交。开仓时间只查一次，最多往前查 26 周。
  - OKX、Gate、Hyperliquid：持仓数据里直接给出。
  - `≥` 表示仓位比交易所能返回的成交记录还早。
  - 连接时、仓位大小变化后、每次结算后刷新，从不轮询。
- 在行内用 *Market* / *Limit* 平仓；✎ 设置整仓或分批止盈止损；*Reverse* 反手；*Close All* 全部平仓；*Hide other symbols* 只看当前交易对；分享按钮生成盈亏卡片。

**账户卡片**：有资金的交易所的权益和可用余额合计（鼠标停留查看每家），以及每家的 uniMMR / 保证金率仪表。

**资产与划转**：*Assets* 标签页或 *Transfer*：在同一交易所的不同账户之间划转（现货、合约、资金账户、理财赎回）。自动补仓：交易账户可用保证金低于阈值时从现货补充（每个交易所每分钟最多一次）。

**仓位保险**：用期权对冲永续仓位（多单买看跌、空单买看涨），在 Binance、Bybit、OKX、Gate、Deribit 之间比价，可在 Bybit 或 Deribit 下单；成本按交易所的真实卖一价计算。Deribit 的币本位期权以 BTC / ETH 计价和支付（确认框同时显示美元价值）。

**模拟交易**（设置 → 交易 → *模拟账户*）：所有交易所共用一个模拟账户和同一笔余额（10,000 USDT；*初始余额* 在下次 *重置* 后生效），不需要 API key。标题栏、下单面板、确认框和账户栏都会显示 **DEMO** 标记；不会向交易所发送任何订单。切换时只重连账户，行情连接不受影响。
- 市价单按该交易所自己的实时订单簿逐档成交（订单簿过期或深度不够时拒绝）。挂着的限价单只有在有成交价穿过它时才成交：你排在队列最后，且不看那笔成交的数量。
- 止损单、追踪止损和止盈止损（Bybit、Binance）按交易所的标记价或最新价触发。资金费在 Depth 运行期间按交易所自己的费率和周期结算。强平按固定 0.5% 维持保证金率（全仓：所有仓位一起强平，没有部分强平）。手续费取 设置 → 交易 里的表格。
- 不模拟：期权、杠杆借贷、划转、交易所托管的 TWAP、延迟。不在屏幕上的交易对用现货最新价当标记价，它的挂单要等它回到屏幕上才会成交。
- 账户是 `depth.db` 里只追加的事件日志（`demo_events`）；重置也只是又一条事件。模拟成交永远不会和真实成交混在一起。

## 8. 设置

## 9. 常见问题

| 问题 | 怎么办 |
|---|---|
| 某个交易所一直是红色 | 你的网络或地区连不上这家交易所，其他交易所照常工作。 |
| *Rate limited, paused until …* | 收到限频回复后，Depth 暂停了对这个域名的请求，到时间会自动恢复。不要反复重启。 |
| 账户数据不显示 | 设置 → API Keys → *Test*；检查 key 的权限和 IP 白名单。 |
| 4H / 1D 上订单簿热力图是空的 | 它从启动开始实时记录；用 1m 或者等一会儿。 |
| 股票 / 商品显示的交易所比预期少 | 有交易所用 Depth 还不认识的名字上市，或者同名的其实是另一个品种。维护者可运行 `python3 scripts/aliases.py` 重新生成别名表。 |
| 崩溃或卡死 | 把 `~/Library/Logs/Depth/panic.log` 附到 [问题报告](https://github.com/ChloePike/depth/issues/new/choose) 里（先删掉个人信息）。 |

**数据存放位置**（macOS）：设置 `~/Library/Application Support/Depth/`，缓存（历史数据、交易对列表、币种图标）`~/Library/Caches/Depth/`，日志 `~/Library/Logs/Depth/`，key 在钥匙串的 `depth` 项下。卸载时删除 app 和这几个文件夹，再在钥匙串访问里删掉 `depth` 相关项。
